# Inbox Zero image provenance

`alpine-dawn.jpg`, `coastal-dusk.jpg`, and `forest-morning.jpg` were generated for Attn with
OpenAI's image-generation tool on August 29, 2026. The original generation used text prompts without
source-image inputs. On the same date, those originals were passed back through the tool as source images
for a composition-preserving HiDPI re-export, then resized to 2560×1440 and encoded consistently as JPEGs.
The app bundles the files and makes no image request at runtime.
