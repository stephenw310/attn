Gmail, from the keyboard.

Attn is an open-source desktop Gmail client for macOS and Windows. It keeps your mail in a SQLite file on your computer, so you can read, write, and sort mail without a connection. Attn has no server.

Developer preview. You build Attn from source and connect it with your own Google OAuth client. Installers come later.

What Attn does

Every mail action has a key
Archive with E, snooze with H, reply with R, and undo with Z. The command palette finds the other actions.
It works without a connection
Attn applies each change to the local database first. It sends the change to Gmail when the connection returns.
Several Gmail accounts
Each account has a separate inbox. The accounts you are not looking at continue to sync and send.
Inbox splits
Sort the inbox into tabs with rules. You can also describe a split in plain words, with your own TypeSafe key.
Drafts and undo send
Attn saves drafts locally and mirrors them to Gmail. You can cancel a send during the undo delay.
AI writing is optional
Reply drafts and inline autocomplete are off by default. They use your own provider key when you turn them on.

Where your mail goes

Mail stays on your computer
Cached mail and drafts are in a SQLite file in your user data directory. Attn does not encrypt that file.
Attn talks to Google directly
There is no Attn server between you and Gmail, and no telemetry.
Keys use the system keychain
The operating system protects your Google tokens and your AI keys through Electron safeStorage.
You can read the code
Attn uses the MIT license. The source for every claim on this page is public.

What setup takes

  1. Get the source Clone the repository and run npm install. You need Node.js 22.12 or later.
  2. Create a Google OAuth client Make a Google Cloud project, enable the Gmail API, and create a Desktop app client. Add your Gmail address as a test user.
  3. Give Attn the client Put the client ID and secret in oauth.config.json. Git ignores this file.
  4. Start Attn Run npm run dev and sign in with Google in your browser.

Google expires the sign-in after seven days while your client is in Testing status. Expect to sign in again each week.
