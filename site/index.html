Your Gmail, kept on your computer.

Attn is an open-source desktop Gmail client for macOS and Windows. It stores your mail in a SQLite file on your computer, so you can read, write, and sort mail without a connection. There is no Attn server.

Developer preview. You build Attn from source and connect it with your own Google OAuth client. Installers come later.

What Attn is

Attn is a mail client, not a service. You sign in to Google from the app, and Attn syncs your mail into a database on your disk. It reads from that database first, so the inbox opens at once and stays usable on a plane. Changes you make offline go to Gmail when the connection returns.

It covers the daily work of mail: several accounts with separate inboxes, archive, snooze, labels, inbox splits with rules, follow-up reminders, and drafts that stay in step with Gmail. Most actions have a keyboard shortcut, and a command palette holds the rest.

AI is optional and off by default. If you add your own provider key, Attn can draft a reply or complete a sentence. If you add a TypeSafe key, it can sort mail into a split that you describe in plain words.

Where your mail goes

Mail stays on your computer
Cached mail and drafts are in a SQLite file in your user data directory. Attn does not encrypt that file.
Attn talks to Google directly
There is no Attn server between you and Gmail, and no telemetry.
Keys use the system keychain
The operating system protects your Google tokens and your AI keys through Electron safeStorage.

What setup takes

  1. Get the source Clone the repository and run npm install. You need Node.js 22.12 or later.
  2. Create a Google OAuth client Make a Google Cloud project, enable the Gmail API, and create a Desktop app client. Add your Gmail address as a test user.
  3. Give Attn the client Put the client ID and secret in oauth.config.json. Git ignores this file.
  4. Start Attn Run npm run dev and sign in with Google in your browser.

Google expires the sign-in after seven days while your client is in Testing status. Expect to sign in again each week.
