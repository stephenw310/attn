What Attn does

Mail stays on your computer
Cached mail and drafts are in a SQLite file in your user data directory. Attn has no server and no telemetry.
Works without a connection
Attn applies each change to the local database first, and sends it to Gmail when the connection returns.
Several Gmail accounts
Each account has a separate inbox. The accounts you are not looking at continue to sync and send.
A key for each action
Archive, snooze, reply, and undo each have a shortcut. The command palette finds the rest.
Inbox splits
Sort the inbox into tabs with rules. You can also describe a split in plain words, with your own TypeSafe key.
Snooze and follow-up
Send a conversation away until a time you choose, or ask for a reminder if nobody replies.
Drafts and undo send
Attn saves drafts locally and mirrors them to Gmail. You can cancel a send during the undo delay.
AI writing is optional
Reply drafts and inline autocomplete are off by default. They use your own provider key when you turn them on.

Keys use the system keychain, and the code is public under the MIT license. Read the privacy policy

Build Attn from source.

Attn is a developer preview. Clone the repository, run npm install, and connect Gmail with your own Google OAuth client. The README has the steps.

Read the setup guide View the source on GitHub

You need Node.js 22.12 or later. Google expires the sign-in after seven days while your OAuth client is in Testing status.
