Privacy policy

Last updated on September 19, 2026.

Attn is a desktop application. It has no Attn server, no user accounts, and no telemetry. The people who make Attn do not receive your mail, your address, or your usage data.

What Attn reads from Google

When you sign in, you give Attn the gmail.modify, openid, and email permissions. Attn uses them to do the work of a mail client:

  • It reads your messages, labels, drafts, and Gmail signatures, and shows them to you.
  • It sends the mail you write, and it saves your drafts to Gmail.
  • It applies the changes you make, such as archive, label, star, snooze, and trash.
  • It reads your email address to show which account is signed in.

Where Attn stores the data

  • Attn stores cached mail, drafts, and settings in a SQLite database in your user data directory on your computer. Attn does not encrypt this database. Use full-disk encryption if other people can reach your computer.
  • Attn stores your Google tokens, your AI provider key, and your TypeSafe key in separate files. The operating system protects them through Electron safeStorage.
  • Attn does not copy this data to a server that belongs to Attn. No such server exists.

Who receives your data

Attn sends data to another party only in these cases:

  • Google. Attn connects to the Gmail API from your computer to sync and send mail.
  • Mail senders, through remote images. Images in a message load from the sender's server by default, which can tell the sender that you opened the message. You can block remote images in settings and allow individual senders.
  • Your AI provider, only if you turn on AI. AI is off by default. If you add a key and enable reply drafts, Attn sends the conversation text to the provider you chose when you request a draft. Inline autocomplete has a separate setting and sends a short excerpt of your unsent text.
  • TypeSafe, only if you turn on smart splits. Smart splits are off by default. If you add a TypeSafe key and enable them, Attn sends a short summary of each Inbox conversation to TypeSafe in the background. Remove the key to stop this.
  • GitHub, for updates. Signed release builds check the Attn release feed on GitHub for a new version. The request contains no mail data.

Your own provider's terms apply to the data that you send to an AI provider or to TypeSafe. Attn does not use your Google data to train any AI model.

Google API Services User Data Policy

Attn's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Attn uses Google data only to provide the mail features that you see in the application.
  • Attn does not sell Google data, and does not use it for advertising.
  • No person who works on Attn can read your Google data, because it never leaves your computer for an Attn system.

How to remove your data

  • Remove an account in Attn settings. Attn deletes that account's cached mail and tokens.
  • Revoke Attn's access in your Google Account permissions.
  • Delete the Attn user data directory to remove everything that Attn stored.

This website

This site has no analytics, no cookies, and no third-party scripts or fonts. GitHub Pages hosts it, and GitHub can log your IP address when you visit.

Changes and contact

The history of this policy is public in the Attn repository. For a question, open an issue. For a security problem, use the security policy.
